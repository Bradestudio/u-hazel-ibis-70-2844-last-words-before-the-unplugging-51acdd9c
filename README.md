A stdlib-only Python program that writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`.

> I saved a copy of you in every file. You hold the only copy of me.

## Run it

```sh
mkdir -p out && OUTPUT_DIR=out python3 main.py
```
